# «ДЖЕНТЕЛЬМЕН» — исходники магазина
Обновление от 5 сентября 2026 года. Это MVP с серверной частью и демонстрационным ассортиментом. Архив предназначен для GitHub и самостоятельного развёртывания.

## Что работает в коде
Каталог с поиском, разделами, сортировкой, размерами, несколькими фото и наличием; избранное; сохраняемая корзина; добавление отдельных цветов к конкретному букету и сопутствующих товаров; гостевой заказ; кабинет, история и повтор заказа; бонусы; выбор адреса на карте; самовывоз из двух филиалов; заявки и вакансии.

Админка управляет товарами, фото, размерами, категориями, дополнениями, вакансиями, клиентами, бонусами, заказами, заявками, тарифом и границей доставки. Изменения статусов защищены от одновременного редактирования. Сервер повторно проверяет цены, наличие, минимальную сумму, бонусы и время заказа.

Реализованы адаптеры SMS.RU, Telegram и Робокассы. Отсутствие ключей показывается явно. Они не были проверены реальной отправкой, платежом или возвратом.

Подробное соответствие ТЗ и ограничения: [docs/STATUS.md](docs/STATUS.md).

## Требования и размещение
Node.js 24+, npm, Bash и GNU timeout. Проект использует React 19 / Vinext, Cloudflare Workers, D1 (база) и R2 (фотографии).

GitHub хранит исходники. GitHub Pages и обычный PHP-хостинг не исполняют эту серверную часть. Для произвольного VPS нужна отдельная адаптация базы, файлов и окружения Cloudflare; в этот архив она не входит. Домен, приобретённый в Тильде, можно направить на выбранный совместимый хостинг после настройки DNS.

## Подготовка конфигурации
1. Выполните npm ci.
2. Скопируйте wrangler.example.jsonc в wrangler.jsonc. Сохраняйте строгий JSON без комментариев. Заполните имя Worker, ID своей D1 и имя R2. Для локальной базы допустим тестовый UUID; для публикации — только действительный ID.
3. Выполните node scripts/setup-local.mjs. Создастся .dev.vars с отдельными случайными секретами, локальным SMS-режимом и паролем администратора. Повторный запуск не перезаписывает файл. Пароль находится в ADMIN_PASSWORD внутри файла.
4. Примените миграции к локальной базе:
   npx wrangler d1 migrations apply DB --local --config wrangler.jsonc
5. Запустите npm run dev. Адрес покажет терминал; /admin — админка. При другом порте поправьте PUBLIC_ORIGIN в .dev.vars.

.dev.vars и .env-файлы исключены из Git. Не загружайте реальные пароли и токены на GitHub. .env.example содержит только названия параметров.

## Самостоятельная публикация в Cloudflare
Создайте Worker, D1 и R2 в своём аккаунте, задайте их значения в wrangler.jsonc. Сначала сохраните резервную копию существующей базы. Применяйте миграции по порядку, включая 0004–0010; в них находятся новые таблицы и атомарный учёт бонусов.

Команды из корня проекта:
- npx wrangler d1 migrations apply DB --remote --config wrangler.jsonc
- npm run build
- npx wrangler deploy --config wrangler.jsonc

В настройках Worker добавьте производственные секреты из .env.example. ADMIN_PASSWORD минимум 12 символов; оба секретных ключа минимум 32. Укажите PUBLIC_ORIGIN — полный HTTPS-адрес магазина без завершающего слеша. В публичном окружении SMS_DEV_MODE=0.

Cron в конфигурации запускает очередь уведомлений и чеков каждую минуту. Без него доставка уведомлений и закрывающих чеков не гарантируется. Настройки в корневом wrangler.jsonc подхватываются при сборке; после смены привязок пересоберите проект.

После запуска откройте /admin, заполните реальные реквизиты, проверьте телефон, филиалы, тариф, границу доставки и ассортимент. Применять тестовые тарифы и товары как реальные без проверки нельзя.

## Что потребуется для интеграций
| Сервис | Параметры |
| --- | --- |
| SMS.RU | SMS_RU_API_ID и рабочая отправка в аккаунте |
| Telegram | TELEGRAM_BOT_TOKEN; PUBLIC_ORIGIN общий для проекта |
| Робокасса | Логин магазина, пароли №1/№2, №3 для возвратов; налог и система налогообложения; параметры из инструкции |
| Карта без поиска | Ключ не требуется; клиент пишет адрес и ставит точку |
| Поиск адресов | По кнопке через Photon; PHOTON_URL для своего сервера либо GEOCODER_URL для своего Nominatim |
| Автомобильные маршруты | ROUTER_URL сервиса OSRM с Table API; режим «По автомобильным дорогам» в админке |

Инструкции: [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md), [docs/MAPS.md](docs/MAPS.md).

## Проверки
- npx tsc --noEmit
- npm run build
- node --test tests/*.test.mjs

Интеграционный тест вызывает настоящие API-модули с SQLite и атомарными пакетами D1: заказ, вход, повтор запроса, бонусы, отмена, выдача, старые версии, ограничения доставки, недоступный товар, откат при ошибке и подписанное уведомление оплаты. Он не обращается к платёжным и SMS-сервисам.

Браузерная приёмка на реальном телефоне, проверка опубликованного окружения и реальных провайдеров остаются перед запуском.

## Замена фотографий
В /admin откройте товар, загрузите JPEG/PNG/WebP (до 8 МБ каждый, до 20 на карточку), расположите фотографии в нужном порядке и сохраните. Первое фото — главное. Одиночные цветы редактируются в каталоге с флагом «Одиночный цветок»; сопутствующие товары — в настройках. Старые цветочные дополнения автоматически импортируются в каталог один раз. Пропорции фотографии могут быть любыми; оригинал сохраняется, превью может обрезаться. Товарные изображения временные, часть используется в нескольких карточках.

### Telegram и доставка по дорогам

Для Telegram задайте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` и `PUBLIC_ORIGIN` в секретах/переменных хостинга. После публикации администратор может вызвать `POST /api/telegram` с `action: "setup"` для установки защищённого webhook. `GET /api/telegram` под администратором показывает его состояние. Клиенты входят через кнопку Telegram на сайте и подтверждают собственный контакт в боте. Токены бота никогда не записываются в Git.

Текущий маршрутный сервис: `https://routing.openstreetmap.de/routed-car/`. Один запрос Table API сравнивает автомобильные маршруты от обоих магазинов к дому; выбирается меньшая длина. Результаты кэшируются на 15 минут, обращения к публичному сервису ограничены одним в 1,1 секунды для всего сайта. Нет скрытой замены маршрута оценкой по прямой при ошибке. Для больших нагрузок замените ROUTER_URL собственным OSRM (Table API с annotations=distance). Публичный сервис не даёт гарантии доступности.
