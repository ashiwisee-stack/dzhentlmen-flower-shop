# Обновление магазина 8 сентября 2026

Вход через Telegram и уведомления используют один бот. Вход не подключает уведомления автоматически и не выдаёт права сотрудника. Клиент подтверждает собственный российский номер кнопкой в личном чате; на сайте и в боте сверяет шестизначный код. Ссылка действует 10 минут, привязана к исходному браузеру, используется один раз. Для следующего входа номер подтверждается снова. Вход по звонку отложен.

## Telegram

Бот: @Gentlemenflowes_bot. Токен находится только в защищённой среде текущего сайта; в архиве его нет. Для переноса задайте TELEGRAM_BOT_TOKEN, TELEGRAM_BOT_USERNAME, TELEGRAM_WEBHOOK_SECRET и PUBLIC_ORIGIN.

Webhook: https://dzhentlmen-flowers.zawanhanuman.chatgpt.site/api/telegram/webhook, allowed_updates=["message"]. При смене домена повторно зарегистрируйте webhook через админку → Настройки → Telegram → Создать ссылку подключения сотрудника. Секрет webhook передаётся Telegram через secret_token.

Для уведомлений владельцу: в админке создайте ссылку, откройте её своим Telegram и нажмите Start. Для каждого сотрудника создавайте новую ссылку. Бот не может начать переписку без первого действия пользователя; пользовательские chat_id заранее неизвестны. Команда /stop отключает уведомления. Уведомления отправляются после действий с заказами, сохраняются в очереди; неотправленные можно повторить в админке. На собственном хостинге настройте периодический обработчик очереди.

## Робокасса — только тест

Тестовые MerchantLogin и пароли уже сохранены в среде сайта, алгоритм MD5, IsTest=1. В тестовом режиме чек не передаётся: налоговые данные продавца ещё не известны. Реальные фискальные чеки и возвраты заблокированы для тестовых заказов. Не переносите тестовые заказы в реальные платежи.

В технических настройках магазина Робокассы нужно проверить три адреса:

| Поле | Значение | Метод |
|---|---|---|
| ResultURL | https://dzhentlmen-flowers.zawanhanuman.chatgpt.site/api/payment/result | POST |
| SuccessURL | https://dzhentlmen-flowers.zawanhanuman.chatgpt.site/payment?result=success | GET |
| FailURL | https://dzhentlmen-flowers.zawanhanuman.chatgpt.site/payment?result=fail | GET |

Пароли интеграции не дают доступа к изменению настроек в личном кабинете Робокассы. После указания URL можно пройти тестовый заказ на сайте. Только подписанное серверное уведомление с правильной суммой меняет оплату на подтверждённую; возврат браузера на страницу оплаты этого не делает.

Для боевого запуска нужны реальные пароли №1/№2, данные налогообложения и фискализации, проверка рабочего чека. Пароль №3 нужен для реальных возвратов. ROBOKASSA_TEST=0 включать только после этих настроек. Вызовы боевых чеков/возвратов не проверены на реальном аккаунте.

## Условия магазина

Начисление бонусов — 5% от стоимости товаров после списания бонусов; начисление после выдачи заказа, доставка не входит. Списать можно до 50% стоимости товаров. Один балл — один рубль скидки.

Первые 2 км бесплатны, далее 50 ₽/км. Неполный километр оплачивается пропорционально: 2,1 км — 5 ₽, 3 км — 50 ₽. Расстояние округляется до 0,1 км, стоимость до рубля. Сохранён бесплатный приблизительный расчёт по прямой ×1,28 от ближайшей мастерской; это НЕ дорожный маршрут. Для точных дорог нужен сервер маршрутов ROUTER_URL и режим road. Поиск по тексту требует GEOCODER_URL; ручной ввод и отметка на карте работают без него. Атрибуция Leaflet без флага, OSM-ссылка сохранена.

Автоматический процесс удаления всех клиентских данных по срокам не реализован — это обязанность оператора, а не свойство опубликованной страницы. Текст не гарантирует отсутствие юридических рисков.
