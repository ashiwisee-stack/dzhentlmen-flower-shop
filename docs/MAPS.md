# Карта, адрес и стоимость доставки

Клиент вводит улицу и дом, открывает карту, отмечает дом нажатием или переносит маркер. Можно разрешить определение местоположения. Квартира, подъезд, этаж и домофон вводятся отдельно. После подтверждения показываются километры и стоимость. Сервер подписывает расчёт на 15 минут и проверяет подпись, адрес и зону при создании заказа.

## Режим без ключей и дополнительных серверов
OpenStreetMap показывает карту без коммерческого API-ключа. Поиск по кнопке «Найти» подключён к Photon. Выбор результата подставляет адрес, отмечает точку и рассчитывает доставку. При недоступности поиска можно вручную указать адрес и точку. Расстояние — геодезическое × 1,28, минимум 1 км; это оценка, не автомобильный маршрут. Интерфейс прямо сообщает об этом. Действующий тариф и способ расчёта берутся из настроек магазина; обновление не перезаписывает сохранённый тариф.

Граница по умолчанию — пример прямоугольной зоны внутри Екатеринбурга, не официальная административная граница всего города. Администратор редактирует контур на карте и сохраняет настройки. Реальный охват и тариф нужно согласовать с магазином.

Публичные тайлы OSM подходят для обычного просмотра с атрибуцией и кешированием, но не дают SLA и не разрешают массовую загрузку. Не включайте предзагрузку всей карты. При росте нагрузки замените tileUrl в настройках через API на собственный совместимый HTTPS-шаблон. Условия: https://operations.osmfoundation.org/policies/tiles/

## Поиск адресов и маршрут по дорогам
В коде предусмотрены следующие адаптеры:
- PHOTON_URL — базовый HTTPS URL своего Photon. Без параметра используется https://photon.komoot.io/. Значение disabled выключает этот поиск. Запрос отправляется только по кнопке/Enter, ограничивается зоной доставки; квартира и контактные поля не передаются. Публичный сервер допускает умеренную нагрузку и не предоставляет SLA: [документация Photon](https://github.com/komoot/photon). Для большой нагрузки нужен свой сервис. GEOCODER_URL имеет приоритет.
- GEOCODER_URL — HTTPS-корень своего Nominatim. Магазин вызывает search с параметрами q, format=jsonv2, limit=8, addressdetails=1. Ответ — массив display_name/lat/lon. Адреса вне заданной зоны отбрасываются.
- ROUTER_URL — HTTPS-корень своего OSRM с автомобильным графом Екатеринбурга и окрестностей. Магазин вызывает route/v1/driving/{lon,lat};{lon,lat}?overview=false. Используется distance первого маршрута; сравниваются маршруты от обоих филиалов. Данные дороги не учитывают живые пробки.

Разверните сервисы на своём VPS с достаточными ресурсами, загрузите актуальную региональную выгрузку OSM, настройте HTTPS, ограничение доступа/нагрузки на прокси и резервное копирование. PostgreSQL Nominatim не выставляйте в интернет. После проверки двух URL задайте параметры Worker и выберите в админке «По автомобильным дорогам». В этом режиме сбой маршрутизатора не подменяется приблизительным расчётом: клиенту предлагается повторить или выбрать самовывоз.

Рекомендуемый порядок подготовки OSRM из документации: osrm-extract с car.lua, osrm-partition, osrm-customize; запуск osrm-routed --algorithm mld. Весь этот путь выполняется на сервере карт, не внутри Worker. Конкретные ресурсы зависят от размера выгрузки. Запуск и нагрузочное испытание этих серверов в рамках подготовки архива не выполнялись.

ПО с открытым исходным кодом не требует платного ключа за запрос; VPS, хранение, обновления и обслуживание могут стоить денег. Поэтому обещание «точные расстояния совершенно бесплатно без настройки» было бы неверным.

Первичные инструкции: https://github.com/Project-OSRM/osrm-backend ; https://nominatim.org/release-docs/latest/admin/Installation/ ; https://github.com/mediagis/nominatim-docker

Публичный Nominatim не используется как скрытая замена: для него действуют ограничения по нагрузке, автодополнению и персональным данным. Условия: https://operations.osmfoundation.org/policies/nominatim/
