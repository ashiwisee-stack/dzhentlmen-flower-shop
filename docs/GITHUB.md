# Исходники и GitHub

Архив содержит исходники проекта. Для GitHub распакуйте ZIP и загрузите содержимое папки Dzhentlmen-flower-shop в корень репозитория. Сам ZIP можно приложить к Release, но для разработки нужны распакованные файлы.

Не загружайте .dev.vars, реальные .env, пароли и токены. .env.example содержит только образец конфигурации. Установка зависимостей: npm ci, Node.js 24+. Подготовка и развёртывание описаны в README.md. Новые миграции 0009 и 0010 обязательны для последней версии.

GitHub хранит код. GitHub Pages не запускает сервер этого магазина: нужны Cloudflare Workers, D1 и R2 или отдельная адаптация под другую инфраструктуру. Пароль админки задаётся через ADMIN_PASSWORD, секрет сессии через ADMIN_SESSION_SECRET; в исходниках их нет.

.openai/hosting.json сохраняет идентификатор текущего опубликованного Sites-проекта. Он не является секретом. При работе с этим сайтом сохраняйте его, чтобы не создавать второй проект. При самостоятельном развёртывании в своём Cloudflare используйте wrangler.example.jsonc и инструкции README.

Данные работающей базы, загруженные через админку фотографии и секреты сервера не входят в исходный архив. Для переноса уже наполненного магазина дополнительно экспортируйте D1 и содержимое R2.
