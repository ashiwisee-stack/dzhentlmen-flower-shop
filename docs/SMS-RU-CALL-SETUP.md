# Тест входа по звонку SMS.RU — 12 сентября 2026

Интеграция добавлена к версии с правками из «Правки.docx». Telegram остаётся самостоятельным способом входа. Пользователь указывает имя и российский номер, звонит с него на выданный номер и возвращается в тот же браузер. Подтверждение проверяется сервером SMS.RU. Сессия и аккаунт создаются только после подтверждения. Если такой телефон уже зарегистрирован через Telegram, используется тот же аккаунт.

Это callcheck (пользователь сам звонит), не звонок с четырьмя цифрами и не отправка SMS. Описание протокола: [официальная документация SMS.RU](https://sms.ru/api/call). Провайдер отводит пять минут на звонок. Проверка статуса в этой версии выполняется через API, отдельный webhook SMS.RU не нужен.

## Что задать при самостоятельном деплое

Секреты не включены в архив. API-ключ со скриншота не использовался для реальных запросов. Замените опубликованный в переписке ключ в кабинете SMS.RU и установите новый в защищённые настройки сервера.

| Переменная | Значение для теста |
| --- | --- |
| SMS_RU_API_ID | Ваш действующий api_id из SMS.RU; только серверный секрет |
| SMS_RU_CALLCHECK_ENABLED | 1 |
| SMS_RU_CALLCHECK_ALLOWED_PHONES | Ваш российский номер, 11 цифр начиная с 7; несколько номеров через запятую |
| SMS_RU_CALLCHECK_DAILY_LIMIT | 5 либо меньший лимит |
| SMS_RU_SMS_ENABLED | 0, чтобы старый API SMS-кодов не расходовал баланс |
| SMS_DEV_MODE | 0 на опубликованном сайте |

Не меняйте действующие настройки Telegram, Робокассы и ключи сессий ради этой интеграции. PUBLIC_ORIGIN должен соответствовать домену сайта. Для локального запуска параметры кладутся в .dev.vars; существующий файл сохраняется. Переменные выше являются строками. Пустой список SMS_RU_CALLCHECK_ALLOWED_PHONES разрешает любые российские номера, поэтому для первоначального теста заполните его своим номером.

SMS_RU_SMS_ENABLED — новый отдельный переключатель для прежнего API SMS-кодов. Если раньше вы использовали реальную отправку кодов, для её сохранения нужно установить 1. В текущем интерфейсе доступны Telegram и звонок; отдельная форма SMS-кодов не добавлялась.

## База и размещение

1. Сделайте резервную копию существующей базы. Установите зависимости (`npm ci`, Node.js 24+).
2. Примените все недостающие миграции. Новая `0010_fresh_korg.sql` создаёт таблицу временных попыток входа. `0009` из предыдущего обновления тоже остаётся необходимой. Существующие заказы и товары не удаляются.
3. Для своего Cloudflare: `npx wrangler d1 migrations apply DB --remote --config wrangler.jsonc`. Для локального теста используйте `--local` вместо `--remote`. Для управляемого Sites — штатное применение миграций публикацией версии.
4. Соберите и разместите исходники обычным способом. Этот архив не был опубликован автоматически.

## Проверка после деплоя

1. Откройте кабинет → «По звонку».
2. Введите имя и свой разрешённый номер, дайте согласие и нажмите «Получить номер для звонка».
3. Позвоните на номер, показанный сайтом, именно с указанной SIM-карты. Не используйте номер из документации: он приведён только как пример.
4. Вернитесь в исходный браузер. Проверка выполняется автоматически каждые 15 секунд, пока вкладка видима; есть кнопка ручной проверки.
5. Убедитесь, что кабинет открылся с правильным телефоном. Повторный вход с тем же телефоном должен открыть тот же аккаунт.
6. Проверьте расход и результат попытки в SMS.RU. Наличие 10 рублей на скриншоте не подтверждает доступность callcheck именно в вашем аккаунте или стоимость попытки; это определяется условиями SMS.RU. Реальный запрос создания может расходовать баланс.

## Защита и ограничения теста

Попытка связана с HttpOnly-cookie исходного браузера; идентификатор проверки SMS.RU не принимается от клиента. Номер из ответа провайдера валидируется, HTML провайдера не вставляется. Неизвестный статус не разрешает вход. Подтверждение одноразовое; создание аккаунта, согласия и сессии выполняется атомарно. Для одного телефона допускается одна действующая попытка. Старые гостевые заказы автоматически к аккаунту не присоединяются.

Лимиты: одна новая попытка на номер в минуту, три за UTC-сутки на номер, пять за десять минут на IP; общий суточный предел задаётся переменной (по умолчанию пять). Общий лимит считает запросы, дошедшие до этого ограничения, а не подтверждённые списания рублей. IP берётся из доверенного заголовка Cloudflare. На другом хостинге нужно адаптировать этот источник к доверенному прокси.

После неопределённого ответа или таймаута создание автоматически не повторяется. Попытка резервируется на пять минут: при необходимости дождитесь срока или отмените её из исходного браузера. Повторный клик в том же браузере использует уже выданный номер. Ограничения действуют и после отмены. Закрытие панели не отменяет попытку; её можно восстановить, снова открыв вкладку «По звонку» в том же браузере.

Автотест проверяет настоящий API-модуль на SQLite с тестовыми ответами SMS.RU: ожидание/подтверждение/истечение, повторный вход, запрет подмены, привязку к браузеру, лимиты, неверные ответы, ошибки сети и отмену одновременно с подтверждением. Реальных запросов к аккаунту SMS.RU, звонков и списаний при подготовке архива не выполнялось. Браузерная приёмка и настоящий звонок остаются после вашего деплоя.
