# Ритм · Android

Локальное приложение на русском: цикл работы 4/2, уход, тренировка пресса и спины, вода и напитки, сон и сводка журнала. Android 8.0+ (API 26), без аккаунта, рекламы, облачной аналитики и разрешения на интернет.

## Установка
Скачайте артефакт **Ritm-Android-1.0.0** из успешного запуска GitHub Actions, распакуйте и откройте **Ritm-1.0.0.apk** на телефоне. Разрешите установку для приложения, через которое открыли APK. Это тестовая сборка с debug-подписью, не публикация в Google Play. Перед переустановкой сохраните резервную копию. Обновления, собранные с другим debug-ключом, могут требовать удаления предыдущей версии: экспортируйте данные до удаления.

При первом запуске выберите день цикла. В настройках измените время подъёма, баню, тренировки и напоминания. По умолчанию часы подъёма 07:00 / 09:00 — это редактируемые начальные значения, а не известный график пользователя.

## Возможности
- Автоматический цикл 1р, 2р, 3р, 4р, 1в, 2в и ручная опорная дата.
- Баня 2р/4р; тренировка 1р/3р/1в с приоритетом восстановления при совпадении.
- Утренний и вечерний уход, отдельные шаги, пропуски, каталог средств и расписания.
- Активные средства по умолчанию не назначены; графики пользователь задаёт самостоятельно.
- Вода, сок, чай и кофе; термос 1 л, долив, отмена ошибочной записи.
- Программа на 30–40 минут с техникой, подходами, весом и таймером отдыха.
- Дневник сна с временем засыпания и оценкой бодрости. Время сна не округляется вниз ради циклов.
- Сводка по 6/7/30 дням; текстовые наблюдения по записям, без диагностики и ложных причинных выводов.
- До 30 сжатых фото, сравнение рядом, удаление. Снимки добавляются пользователем, в код и репозиторий они не включаются.
- Резервная копия JSON с настройками, журналом и фотографиями. Храните копию в защищённом месте.

## Уведомления
Нативный AlarmManager и NotificationChannel. На Android 13+ требуется разрешение на уведомления. Точное время включается отдельно; без разрешения используется системное приблизительное расписание. В тихие часы напоминания не отправляются. График восстанавливается после перезагрузки, обновления приложения и изменения времени. После force-stop Android блокирует фоновые события до повторного открытия приложения. Производитель телефона может дополнительно задерживать события энергосбережением.

Кнопка «Готово» в уведомлении отмечает уход/тренировку, «+250 мл» добавляет обычную воду. Повторное нажатие одного события не дублирует запись; старое уведомление не пишет в новый день. Таймер подходов предназначен для открытого приложения, его отсчёт восстанавливается при возвращении; это не фоновый будильник.

## Приватность и хранение
JSON сохраняется через AtomicFile в приватном каталоге Android. Автоматическое резервирование Android отключено. Фотографии читаются через системный выбор файла, уменьшаются и сохраняются без исходного EXIF. Экспорт выполняется только по действию пользователя через системный диалог. Локальный интерфейс загружается из APK на виртуальном домене; внешние сетевые запросы в WebView заблокированы. Ссылки на источники открываются в отдельном браузере.

## Здоровье
Приложение — дневник и стартовый шаблон активности, не медицинское устройство. Не ставит диагноз по фотографии, не назначает лекарственные дозировки, не обещает изменение костей лица, удаление рубцов, локальное сжигание жира или лечение отёков водой. Активные средства требуют проверки переносимости. Боль при упражнении — повод остановиться.

Сон: кратность 70–90 минут не гарантирует нужную фазу пробуждения. Не нужно сокращать доступный сон ради кратности. Обычный ориентир для взрослых — 7–9 часов.

## Сборка
JDK 17, Gradle 8.11.1, Android SDK 35 / build-tools 35.0.0.
Из каталога ritm-android:
    gradle :app:assembleDebug :app:testDebugUnitTest :app:lintDebug

APK: app/build/outputs/apk/debug/app-debug.apk

В браузере интерфейс можно проверить локальным HTTP-сервером для app/src/main/assets/www. В браузере данные хранятся отдельно, нативные уведомления отсутствуют.

Исходники размещены в отдельной ветке codex/ritm-android. Не объединяйте её с магазином ради сборки APK. Для переноса в самостоятельный репозиторий скопируйте содержимое ritm-android и адаптируйте рабочую директорию workflow.
